tagged `fde:needs-better-sources` rather than fabricated or marked `researched` on no real
content. The zero-resources case here is the same outcome as a topic whose linked resources all
failed to fetch (`rags.md`), just arrived at trivially rather than through failed attempts.

would be easy to fabricate — a system of record is the authoritative source for a given type of
data in an organization — but doing so here would violate the same rule `rags.md` already
established: findings must come from an actually-read source, not parametric/general knowledge
substituting for one.

## Findings

**What front-end development is** (Coursera): "designing and creating the front end...of a
website, application, or other development project" — the interactive, user-facing elements
(colors, buttons, menus, navigation). Day-to-day work spans writing code, designing user
journeys/interfaces, optimizing for speed/security/SEO, testing, structuring layout.

**Core technologies, confirming the HTML/CSS/JS triad already established across `html.md`,
`css.md`, `javascript.md`**: HTML (content placement), CSS (styling), JavaScript
(interactivity) — plus named frameworks Bootstrap, React, Vue, Angular, and version-control/
debugging tooling.

**A concrete, representative curriculum** (Simplilearn's 12-lesson course): Git/GitHub
fundamentals → HTML (with a practical registration-form project) → CSS (styling/animations/
effects) → JavaScript (core concepts, DOM manipulation, `this` keyword) → React → Angular
(including services) — a real-world example of how these previously-researched individual
topics (`html.md`, `css.md`, `javascript.md`, `react.md`, `git-github` — not yet researched)
are sequenced together in practice, version control first, frameworks last.

**Career context** (Coursera): front-end dev vs. full-stack (both ends) vs. adjacent roles
(SEO strategist); ~$81,893 average US salary, 8% projected growth through 2033 — the only
labor-market data point found in this entire category so far.

**Direct relevance to this system**: confirms `learn-a-programming-language.md`'s point that
frontend self-sufficiency lets an FDE "deliver end-to-end demos and prototypes without a
separate frontend team" — this topic's real curriculum ordering (Git → HTML → CSS → JS →
framework) is a usable reference sequence if that skill is ever actually built out for this
system's own (currently nonexistent) frontend needs.

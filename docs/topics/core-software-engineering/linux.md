## Findings

**Linux for Noobs, a concrete 37-lab curriculum** (labex.io): file management (navigate the
filesystem, manage files/directories/links/archives/storage, permissions/ownership);
command-line fundamentals (pipelines, redirection, regex, `grep`/`sed`/`awk` text processing);
system administration (inspect processes, install software, manage services, read logs,
diagnose DNS/port/firewall issues); remote access/automation (SSH/SCP, Bash scripting,
backup creation/verification/scheduling/restoration). Structured as 19 guided lessons + 18
independent challenges, no prerequisites.

**Linux Journey's three-tier skill progression** (labex.io), a genuinely useful map of Linux
depth: Grasshopper/beginner (distro choice/installation, CLI basics, text editing, user
management, file permissions, processes, package managers like apt-get/rpm); Journeyman/
intermediate (device interaction, filesystem architecture, boot process, kernel config, init
systems — SysV/Upstart/systemd — resource monitoring, system logging); Networking Nomad/
advanced (rsync/scp/nfs, TCP/IP, subnetting, routing, network troubleshooting, DNS). Also
offers RHCSA/CompTIA Linux+/Network+ certification prep — real, named industry certifications.

**Direct relevance to this system — the most practically load-bearing topic in this entire
category alongside `git-github.md`**: this project's own `uv run pytest`, `ffmpeg` pipeline
helpers (from the sibling music-pipeline project, same user), Bash tool usage throughout every
session, and the Mac Mini deployment plan (flagged as a pending task in the broader Cimcime
project) all depend directly on exactly the skills named here — file permissions, process
management, log reading, package management, and Bash scripting are not background knowledge
for a hypothetical future engagement; they are used continuously, every session.

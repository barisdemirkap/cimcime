## Findings

**What React is** (react.dev, translated from Spanish): "a library for web and native user
interfaces" — build UIs from reusable components (e.g. buttons, thumbnails) composed into full
applications. Components are plain JavaScript functions: "learning React is learning to
program" — standard JS logic (conditionals, array methods), not proprietary syntax. JSX
combines markup with its related rendering logic in one place for maintainability. Enables
shared-skill cross-platform development (web + iOS + Android).

**Virtual DOM mechanism** (w3schools): React builds an in-memory virtual DOM first, diffs it,
and applies only the necessary changes to the real browser DOM — the core performance
optimization that distinguishes it from direct DOM manipulation.

**Origin and prerequisites** (w3schools): created by Facebook engineer Jordan Walke, emerged
from Facebook's 2011 Newsfeed feature, first public release v0.3.0 in July 2013, current
version 19.2 (as of this fetch). Assumes prior HTML/CSS/JS knowledge — directly builds on
`html.md`/`css.md`/`javascript.md` already researched in this same category.

**Direct relevance to this system**: minimal directly — no React in this project — but it's
the concrete named frontend framework already flagged in `learn-a-programming-language.md`'s
tech-stack finding ("React for front-end, NextJS for back-end" per that topic's JS-roadmap
source) as the FDE's standard choice when a client-facing UI is needed.

## Findings

**What a Java developer does** (roadmap.sh): builds web apps (AEM, Liferay), desktop apps
(Eclipse IDE), and enterprise systems (ERP, CRM) — commonly in financial, healthcare, telecom,
and data industries. Backend focus dominates: server-side logic, database management,
inter-application communication via Spring Boot and Hibernate.

**Required skills** (roadmap.sh): strong Java/OOP foundation; JVM internals, concurrency,
memory management; Hibernate + SQL (Oracle named specifically); REST APIs; testing tools and
modern engineering practice.

**Career framing — explicitly long-horizon**: the roadmap emphasizes "Java's 30-year
relevance," strong community, global demand — framing Java as the stable-enterprise choice
rather than a fast-moving one, which directly corroborates `learn-a-programming-language.md`'s
earlier finding that Java shows up specifically "in large enterprise or government client
environments" with existing Java codebases — this topic adds the *why*: those environments
value exactly the multi-decade stability Java is known for.

**Scala**: the roadmap.sh page for Scala did not render its actual curriculum (landing-page
header only, same JS-SPA limitation seen for several other roadmap.sh pages); no other
resource for Scala was reachable. What's known about Scala from the roadmap doc's own topic
description (not independently verified): JVM-based, blends OOP and functional styles, common
in Spark-based data processing — this connects directly to `spark.md`/data-engineering topics,
unresearched detail beyond that one-line description.

**Direct relevance to this system**: none directly — this project has no Java/Scala code — but
this topic reinforces the "match the language to the client's actual stack" principle (already
found three times: `learn-a-programming-language.md`, `python.md`, `javascript.md`): an
engagement at a bank or government client would require fluency here regardless of personal
language preference.
